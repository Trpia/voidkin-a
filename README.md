# Voidkin AI

**Free AI Video Studio** built with Kivy.

## Features
- Dark modern UI
- Text prompt input
- Aspect ratio selection (9:16, 16:9, 1:1)
- Duration selection
- Style selection (Cinematic, Anime, Cyberpunk, etc.)
- Generates simple text-based videos (using MoviePy)

## How to run (Computer)

```bash
pip install -r requirements.txt
python main.py
